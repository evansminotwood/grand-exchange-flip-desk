# GE Flip Desk

An Old School RuneScape Grand Exchange flipping analyzer. It ranks items by after-tax margin, ROI, volume and buy limits using live data from the [OSRS Wiki real-time prices API](https://prices.runescape.wiki), and charts each item's buy/sell history with a plain-language analysis.

Live site: https://evansminotwood.github.io/grand-exchange-flip-desk/
